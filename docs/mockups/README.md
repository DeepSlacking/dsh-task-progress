# Scene mockups

`scenes.html` is a self-contained, fictional DSH-style scene used to render the two screenshots in `docs/images/`:

- `scene-progress.png` — open `scenes.html?scene=rail`
- `scene-completed.png` — open `scenes.html?scene=completed`

The page is a standalone static document (1600 × 1000, rendered at 2× device scale). It uses only system fonts and inline SVG; no real session data, account, or conversation is used.
